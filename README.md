# Accelulator

**Accelulator** is a finance-led web platform that helps teams forecast, manage, and understand their people costs.

This is the working codebase for the site, including the early-stage tools and logic powering the first feature: **StaffCast** — a smart, month-by-month staff cost forecaster for finance and HR teams.

---

## 🚀 Features in Development

- People cost forecasting (base pay + employers’ NI)
- Actuals + outturn separation
- Monthly breakdowns and variance tracking
- Clean UI built with vanilla PHP and JavaScript
- Data uploaded via template or entered directly
